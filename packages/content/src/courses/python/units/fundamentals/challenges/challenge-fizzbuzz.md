# FizzBuzz

## Objective

Print numbers from 1 to 20. For multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz". Otherwise print the number itself.

## Expected Output

```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
16
17
Fizz
19
Buzz
```

## Hints

- Use the modulo operator `%` to check divisibility.
- Check the `FizzBuzz` condition (divisible by both 3 and 5) before the individual checks.
