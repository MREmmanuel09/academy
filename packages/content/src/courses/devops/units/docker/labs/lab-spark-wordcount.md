# Primer job Spark: Word Count sobre un archivo de texto

**Objetivo**: Ejecuta el "Hello World" de Big Data: contar palabras de un archivo de texto usando Apache Spark. Creas la SparkSession, lees el archivo, aplicas transformaciones (flatMap, map, reduceByKey) y recoges los resultados con collect().
