# AWS Resource Reporter: cost optimization

**Objetivo**: Construir un script con boto3 que liste todos los recursos de AWS en una region (EC2, RDS, S3, ELB), identifique los que no tienen tags obligatorios, y genere un reporte CSV/JSON para cost optimization. Aplicable a FinOps.
