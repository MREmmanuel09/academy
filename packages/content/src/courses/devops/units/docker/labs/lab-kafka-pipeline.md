# Pipeline Kafka end-to-end: producer, broker, consumer

**Objetivo**: Construye un pipeline completo de eventos: inicias un broker Kafka, creas un topic, lanzas un producer que envia mensajes JSON simulando clicks de usuarios, y un consumer que los lee y los persiste a un archivo.
