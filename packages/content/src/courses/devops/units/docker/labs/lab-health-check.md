# System Health Checker con alertas Slack

**Objetivo**: Crear un script Python que verifique CPU, memoria, disco y servicios systemd en un servidor, y envie alertas a Slack via incoming webhook cuando algun threshold se exceda. Debe correr periodicamente con cron o schedule.
