# Log Analyzer CLI: parsea logs nginx/apache

**Objetivo**: Construir una herramienta CLI en Python que analice logs de nginx/apache, identifique errores 4xx/5xx, IPs mas frecuentes, y paths mas solicitados. Debe aceptar el archivo de log como argumento y exportar un reporte JSON.
