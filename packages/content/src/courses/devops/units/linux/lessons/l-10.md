# Logs y troubleshooting

grep, awk, sed, journalctl, /var/log. Encontrar el problema en logs.

## Dónde están los logs

### Directorio /var/log

```
/var/log/
├── syslog              # log general del sistema
├── auth.log            # autenticación, sudo, ssh
├── kern.log            # mensajes del kernel
├── nginx/
│   ├── access.log      # todas las requests HTTP
│   └── error.log       # errores
├── apache2/
├── mysql/
├── apt/
├── dpkg.log
└── journal/            # systemd journal
```

### Comando logger

Para escribir al syslog:

```bash
logger "Mi mensaje de prueba"
logger -p user.err "Esto es un error"
```

### rsyslog y syslog

El demonio **rsyslog** o **syslog-ng** recoge mensajes de todo el sistema. Config en `/etc/rsyslog.conf`.

Cada mensaje tiene una **facilidad** (auth, kern, mail, local0-7) y un **nivel** (debug, info, warning, err, crit, alert, emerg).

## Buscar en logs como un pro

### grep - el caballito de batalla

```bash
grep "error" archivo.log
grep -i "error" archivo.log             # case-insensitive
grep -v "info" archivo.log              # excluir
grep -n "fail" archivo.log              # con número de línea
grep -c "404" access.log                # contar matches
grep -r "TODO" src/                     # recursivo
grep -E "error|fail|critical" log.txt   # regex extendido (alternation)
grep -A 3 "Exception" app.log           # 3 líneas después del match
grep -B 2 "Error" app.log               # 2 líneas antes
```

### awk - procesador de texto

```bash
# Extraer columna 1 (IPs) de un access log
awk '{print $1}' access.log

# Sumar valores
awk '{sum += $5} END {print sum}' access.log

# Filtrar y procesar
awk '$9 == 404 {print $1, $7}' access.log
# $9 = status code, $1 = IP, $7 = URL

# Sumar por status code
awk '{codes[$9]++} END {for (c in codes) print c, codes[c]}' access.log
```

### sed - editor de streams

```bash
sed 's/old/new/' archivo.txt            # primera ocurrencia por línea
sed 's/old/new/g' archivo.txt           # todas las ocurrencias
sed -i 's/old/new/g' archivo.txt        # in-place (modifica el archivo)
sed '/^$/d' archivo.txt                 # borrar líneas vacías
sed -n '10,20p' archivo.txt             # imprimir líneas 10-20
sed 's/^/  /' archivo.txt               # indentar
```

### Combinando

```bash
# Top 10 IPs en un access log
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10

# Errores 5xx de las últimas 1000 líneas
tail -1000 access.log | awk '$9 ~ /^5/ {print $1, $7, $9}'

# Top URLs con error
grep " 5[0-9][0-9] " access.log | awk '{print $7}' | sort | uniq -c | sort -rn | head
```

## Puntos clave

- /var/log contiene todos los logs del sistema. auth.log, syslog, kern.log.
- grep encuentra patrones. -i case-insensitive, -v excluir, -E regex.
- awk procesa texto por columnas ($1, $2, $NF). sed transforma en stream.
- Pipe chain: awk | sort | uniq -c | sort -rn | head -10 es un clásico de DevOps.
