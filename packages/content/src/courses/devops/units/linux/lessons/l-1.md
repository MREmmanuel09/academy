# ¿Qué es Linux y por qué DevOps lo usa?

Historia de Linux, distribuciones, y por qué es el sistema operativo dominante en servidores y DevOps.

## Historia y filosofía

**Linux** es un sistema operativo de código abierto creado por **Linus Torvalds** en 1991, inspirado en Unix. Su desarrollo se basa en la filosofía del software libre y el modelo bazar (miles de desarrolladores contribuyendo).

**Unix philosophy**: "Haz una cosa y hazla bien". Programas pequeños que se combinan.

**Hoy en día** Linux corre:
- 96% de los top 1 millón de servidores web
- 100% de los supercomputadores TOP500
- Android (basado en el kernel de Linux)
- Tu router, tu smart TV, los cajeros automáticos
- La Estación Espacial Internacional
- La mayoría de los contenedores Docker


## Distribuciones

Una **distribución** = kernel de Linux + herramientas + gestor de paquetes + filosofía.

**Familia Debian**:
- **Debian**: estable, conservadora
- **Ubuntu**: amigable, muy popular en cloud
- **Linux Mint**: para desktop

**Familia Red Hat**:
- **RHEL** (Red Hat Enterprise Linux): estándar en empresas
- **CentOS / Rocky / AlmaLinux**: clones gratuitos
- **Fedora**: cutting edge

**Otras**:
- **Arch**: minimalista, rolling release
- **Alpine**: ultra-liviana, popular en Docker
- **Amazon Linux**: optimizada para AWS

Para DevOps típicamente usarás **Ubuntu, Debian, CentOS, Rocky o Alpine** (en contenedores).

## ¿Por qué DevOps ama Linux?

1. **Gratis y open source**: no pagas licencias
2. **Estable**: corre años sin reiniciar
3. **Seguro**: permisos granulares, SELinux, AppArmor
4. **Automatizable**: todo es un archivo de texto
5. **CLI potente**: bash + ssh = automatización remota
6. **Ecosistema**: Docker, Kubernetes, Terraform, Ansible nacieron en Linux
7. **Cloud-native**: AWS, GCP, Azure ofrecen Linux como principal
8. **Contenedores**: Docker está construido sobre features de Linux (cgroups, namespaces)

> **Regla de oro de DevOps**: si quieres trabajar en serio, **aprende Linux bien**, especialmente la terminal. Es el 80% del trabajo diario.

## Puntos clave

- Linux es open source, creado por Linus Torvalds en 1991.
- Una distribución combina kernel + herramientas + gestor de paquetes.
- Linux domina servidores, cloud, contenedores, mobile y supercomputación.
- DevOps se construye sobre Linux: dominar la terminal es fundamental.
