# Terminal y comandos esenciales

Navegación, archivos, directorios, atajos. Los comandos que usarás todos los días.

## Anatomía de la terminal

El **prompt** se ve así:

```
usuario@hostname:~/directorio$
```

- **usuario**: tu nombre
- **hostname**: nombre de la máquina
- **~/directorio**: ruta actual (~ = home, $ = usuario normal, # = root)

Los comandos siguen el patrón:

```
comando [opciones] [argumentos]
```

Ejemplo: `ls -la /etc`
- `ls`: listar
- `-la`: opciones (largo, todos)
- `/etc`: argumento (directorio)

## Navegación

### Comandos básicos

| Comando | Función |
|---------|---------|
| `pwd` | Print Working Directory - muestra dónde estás |
| `ls` | Lista archivos |
| `cd <dir>` | Cambia de directorio |
| `cd ..` | Sube un nivel |
| `cd ~` | Va a tu home |
| `cd -` | Vuelve al directorio anterior |
| `clear` o `Ctrl+L` | Limpia la terminal |

### Atajos de teclado

- **Tab**: autocompletar (úsalo SIEMPRE)
- **↑/↓**: historial de comandos
- **Ctrl+R**: búsqueda en historial
- **Ctrl+C**: matar proceso actual
- **Ctrl+D**: logout
- **Ctrl+A / E**: inicio / fin de línea

### Trucos pro

```bash
cd /var/log/apache2    # absoluto (desde /)
cd ../etc              # relativo (desde donde estás)
ls -lah               # legible + todo + humano
```

## Comandos de archivos

### Ver, copiar, mover, borrar

| Comando | Función |
|---------|---------|
| `cat archivo` | Muestra contenido |
| `less archivo` | Paginador (q para salir) |
| `head -n 10 archivo` | Primeras 10 líneas |
| `tail -n 10 archivo` | Últimas 10 líneas |
| `tail -f archivo` | Sigue el archivo en vivo (logs) |
| `cp origen destino` | Copiar |
| `mv origen destino` | Mover / renombrar |
| `rm archivo` | Borrar (¡CUIDADO!) |
| `rm -rf directorio` | Borrar recursivo y forzado |
| `mkdir dir` | Crear directorio |
| `touch archivo` | Crear archivo vacío (o actualizar timestamp) |
| `ln -s origen link` | Crear link simbólico |

### ⚠️ EL COMANDO MÁS PELIGROSO

```bash
rm -rf /
```

**NUNCA ejecutes esto.** Borra recursivamente desde la raíz. En servidores reales destruye todo. Hay memes de sysadmins que lo corrieron por error.

> **Tip**: añade alias `alias rm='rm -i'` en tu `.bashrc` para que pregunte antes de borrar.

## Puntos clave

- El prompt muestra usuario, hostname y directorio actual.
- Tab autocompletar es tu mejor amigo. Úsalo SIEMPRE.
- Ctrl+R busca en el historial. Ctrl+C mata el proceso actual.
- `rm -rf` es destructivo. Nunca lo corras sobre `/`.
