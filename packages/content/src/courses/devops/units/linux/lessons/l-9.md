# Gestión de paquetes

apt, yum/dnf, compilar desde fuente. Instalar y mantener software.

## Gestores de paquetes

Un **gestor de paquetes** instala, actualiza y desinstala software. Maneja dependencias automáticamente.

### Debian/Ubuntu (apt)

```bash
sudo apt update                    # actualizar lista de paquetes
sudo apt upgrade                   # actualizar instalados
sudo apt install nginx              # instalar
sudo apt remove nginx               # desinstalar (mantiene config)
sudo apt purge nginx                # desinstalar todo
sudo apt autoremove                 # limpiar dependencias huérfanas
apt search "web server"             # buscar
apt show nginx                      # ver info
apt list --installed                # todos los instalados
```

**Archivos**:
- `/etc/apt/sources.list`: repositorios
- `/var/lib/dpkg/status`: base de datos de paquetes
- `/var/cache/apt/archives/`: descargas

### RHEL/CentOS/Fedora (yum / dnf)

```bash
sudo dnf install nginx
sudo dnf remove nginx
sudo dnf search httpd
sudo dnf info nginx
sudo dnf update
dnf list installed
```

### Alpine (apk)

```bash
apk add nginx
apk del nginx
apk search nginx
apk update
```

> Alpine es la distribución más usada en **contenedores Docker** por su tamaño (~5MB base).

## Snap, Flatpak y AppImage

Para apps de escritorio, los formatos universales evitan el problema de dependencias:

- **Snap** (Ubuntu, ahora universal): `snap install code`
- **Flatpak** (Fedora, otros): `flatpak install flathub com.spotify.Client`
- **AppImage** (universal, un solo archivo): `./app.AppImage`

Para DevOps, no usarás mucho estos. El rey es el gestor de paquetes nativo.

### Repositorios personalizados

A veces necesitas software de fuera del repo oficial:

```bash
# Añadir un PPA en Ubuntu
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.11

# Añadir repo de Docker
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu jammy stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update
sudo apt install docker-ce
```

## Puntos clave

- apt (Debian/Ubuntu), dnf (RHEL/Fedora), apk (Alpine). Patrón: update + install.
- apt purge elimina todo, apt remove mantiene la config.
- Para DevOps: contenedores usan Alpine (apk) o Debian (apt).
- Repositorios personalizados permiten software de fuera del oficial.
