# Sistema de archivos y rutas

Jerarquía FHS, rutas absolutas vs relativas, examinar el filesystem.

## FHS - Filesystem Hierarchy Standard

En Linux todo es un archivo (incluso los dispositivos). La estructura sigue el estándar FHS:

```
/
├── bin/        # Binarios esenciales (ls, cat, cp)
├── sbin/       # Binarios de sistema (para root)
├── etc/        # Archivos de configuración
├── home/       # Directorios de usuarios
│   └── tuusuario/
├── root/       # Home del root
├── var/        # Datos variables (logs, bases de datos)
│   ├── log/    # Logs del sistema
│   └── www/    # Archivos web
├── tmp/        # Archivos temporales (se borra al reiniciar)
├── usr/        # Programas de usuario
│   ├── local/  # Software instalado manualmente
│   └── bin/    # Más binarios
├── opt/        # Software opcional/terceros
├── dev/        # Dispositivos (sda, tty, null)
├── proc/       # Información de procesos (virtual)
├── sys/        # Info del kernel (virtual)
└── mnt/        # Puntos de montaje temporales
```

> **Importante en DevOps**: `/etc` es donde editas config, `/var/log` es donde lees errores.

## Rutas absolutas vs relativas

**Ruta absoluta**: empieza con `/` (desde la raíz)
- `/home/usuario/proyecto`
- `/etc/nginx/nginx.conf`

**Ruta relativa**: desde donde estás
- `./README.md` (archivo en directorio actual)
- `../sibling/file.txt` (subir un nivel, luego entrar)
- `~/proyectos` (~ = tu home)

### Atajos

- `.` = directorio actual
- `..` = directorio padre
- `~` = home del usuario actual
- `~` para `root` es `/root`, para `juan` es `/home/juan`

### Wildcards (globbing)

```bash
ls *.txt           # todos los .txt
ls archivo?        # archivo1, archivoA (1 caracter)
ls [abc]*          # empieza con a, b o c
ls **/*.js         # recursive (bash extglob)
ls archivo{1,2,3}  # archivo1 archivo2 archivo3
```

## Encontrar archivos

### `find` - el caníbal de archivos

```bash
find / -name "*.conf"              # busca desde /
find /etc -name "*.conf"           # en /etc
find / -type f -size +100M         # archivos > 100MB
find . -mtime -7                   # modificados en últimos 7 días
find . -name "*.log" -delete       # borrar todos los .log
find / -user juan                  # archivos de juan
find . -name "*.js" -exec ls {} \; # ejecutar comando en cada match
```

### Alternativas modernas

- `fd` - más rápido, sintaxis simple
- `locate archivo` - busca en índice (más rápido, pero no en tiempo real)
- `which comando` - encuentra ejecutable
- `whereis comando` - encuentra binario, source y man

### `tree` - ver estructura

```bash
tree /etc/nginx
tree -L 2 ~/proyectos  # limita a 2 niveles
```

> Instala con `sudo apt install tree` o `sudo yum install tree`.

## Puntos clave

- Linux sigue el FHS: /etc para config, /var/log para logs, /home para usuarios.
- Rutas absolutas empiezan con /, relativas con ./ o ../.
- `find` es la herramienta definitiva para buscar archivos por nombre, tamaño, fecha.
- Tab autocompleta rutas; wildcards (*, ?, []) ahorran tecleo.
