# Bash scripting

Variables, condicionales, loops, funciones. Automatiza todo.

## Shebang y tu primer script

Un script bash empieza con **shebang**:

```bash
#!/bin/bash
# Mi primer script
echo "Hola, mundo"
```

```bash
chmod +x script.sh
./script.sh
```

Si el script está en tu PATH (`/usr/local/bin`, `~/bin`), puedes invocarlo por nombre.

### Variables

```bash
nombre="Juan"
echo "Hola, $nombre"
echo "Hola, \${nombre}!"          # con llaves para delimitar
readonly PI=3.14                  # constante
unset variable                    # eliminar
```

**Variables especiales**:
- `$0`: nombre del script
- `$1, $2, ...`: argumentos posicionales
- `$#`: número de argumentos
- `$@`: todos los argumentos
- `$?`: exit code del último comando
- `$$`: PID del script
- `$USER`, `$HOME`, `$PWD`: variables de entorno

```bash
#!/bin/bash
echo "Script: $0"
echo "Primer arg: $1"
echo "Total args: $#"
echo "Todos: $@"
```

## Condicionales y loops

### if / else / elif

```bash
if [[ "$1" == "start" ]]; then
  systemctl start nginx
elif [[ "$1" == "stop" ]]; then
  systemctl stop nginx
else
  echo "Uso: $0 {start|stop}"
  exit 1
fi
```

**Comparaciones numéricas**: `-eq, -ne, -lt, -le, -gt, -ge`
**Comparaciones strings**: `==, !=, -z (vacío), -n (no vacío)`
**Archivos**: `-f (existe), -d (directorio), -r (legible), -w (escribible), -x (ejecutable)`

### Loops

```bash
# for
for i in 1 2 3 4 5; do
  echo "Iteración $i"
done

for archivo in *.log; do
  echo "Procesando $archivo"
done

for ((i=1; i<=10; i++)); do
  echo $i
done

# while
contador=0
while [[ $contador -lt 5 ]]; do
  echo $contador
  ((contador++))
done

# until (corre hasta que se cumpla la condición)
until ping -c1 google.com &>/dev/null; do
  echo "Esperando internet..."
  sleep 5
done
```

## Funciones, pipes y exit codes

### Funciones

```bash
saludar() {
  local nombre=\$1
  echo "Hola, $nombre"
}

saludar "Mundo"

# Con return
es_par() {
  if (( $1 % 2 == 0 )); then
    return 0   # éxito
  else
    return 1   # fallo
  fi
}

if es_par 4; then
  echo "Es par"
fi
```

### Pipes y redirección

```bash
cat /var/log/syslog | grep error | tail -20
ps aux | grep nginx | grep -v grep

# Redirección
echo "log entry" >> archivo.log     # append
echo "nuevo" > archivo.txt          # overwrite
comando 2> errores.log              # solo stderr
comando &> todo.log                 # stdout + stderr
comando > /dev/null 2>&1            # descartar todo
```

### Exit codes

```bash
comando_exitoso
echo $?                  # 0 = éxito

comando_fallido
echo $?                  # 127, 1, 2, etc. (no-cero)

# Útil en condicionales
if ping -c1 google.com &>/dev/null; then
  echo "Internet OK"
fi
```

**Exit codes comunes**:
- 0: éxito
- 1: error genérico
- 2: uso incorrecto del comando
- 126: no se puede ejecutar
- 127: command not found
- 130: Ctrl+C
- 137: SIGKILL
- 143: SIGTERM

## Puntos clave

- Un script empieza con #!/bin/bash y se hace ejecutable con chmod +x.
- Variables: $VAR o ${VAR}. Comparaciones: -eq, -lt, ==, -f, -d.
- Pipes (|) encadenan comandos. Redirección (>, >>) envía a archivos.
- Exit code 0 = éxito, no-cero = error. Útil en if/while.
