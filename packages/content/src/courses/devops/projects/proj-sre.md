# Implementa SRE practices en un servicio real

## Escenario

Te unes como unico SRE a un equipo de 8 developers. El servicio tiene 99.5% de disponibilidad (peor que el SLA de 99.9%). Hay toil excesivo: 30% del tiempo en tareas manuales. Tu mision: subir la confiabilidad a 99.95% y reducir el toil a menos de 10%.

## Meta

Implementar SLOs, error budgets, runbooks, y automatizar el toil para llevar el servicio a "managed by automation".
