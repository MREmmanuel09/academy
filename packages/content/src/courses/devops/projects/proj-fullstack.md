# Despliega una aplicacion full-stack production-ready

## Escenario

Una startup te contrata para desplegar su aplicacion web (Node.js API + React frontend + PostgreSQL). Tienen 5000 usuarios diarios y el CTO quiere cero downtime. Presupuesto: $200/mes.

## Meta

Desplegar una aplicacion production-ready con CI/CD, monitoring, backups y rollback automatico en AWS o GCP.
