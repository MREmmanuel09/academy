# Monta un SOC casero con deteccion real

## Escenario

Quieres demostrar skill de seguridad mas alla de la teoria: un laboratorio donde captures trafico real de tu red, detectes escaneos y ataques simulados, y respondas con playbooks. Presupuesto: una maquina con Proxmox o VirtualBox y software open source.

## Meta

Desplegar un mini-SOC funcional: sensor de red con capturas, SIEM con reglas de deteccion, respuesta con ACLs y documentacion de 3 incidentes simulados de principio a fin.
