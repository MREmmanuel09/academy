# Disena la red de un campus de 3 edificios

## Escenario

Una academia con 3 edificios (Aulas, Laboratorios, Administracion) necesita renovar su red. Hay 450 dispositivos entre PCs, impresoras, camaras y APs. Hoy es una sola /24 plana: los broadcasts la saturan y no hay segmentacion entre alumnos y administracion.

## Meta

Entregar un diseno completo y documentado: direccionamiento VLSM, VLANs por uso, routing entre edificios con OSPF, servicios (DHCP/DNS) y endurecimiento basico, listo para implementar.
